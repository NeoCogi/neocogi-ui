# neocogi-appearance

Pure typed appearance compilation shared by NeoCogi GFX construction and Skin.

This package is part of the NeoCogi UI `0.1.0-alpha.1` release.
Use matching UI and Platform packages when building hosts and providers.
The packaged sources build independently of the repository checkout.

See the [NeoCogi UI documentation](https://github.com/NeoCogi/neocogi-ui/tree/master/docs)
for architecture, feature ownership and application examples.
